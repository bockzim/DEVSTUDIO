# Forma Personal (site demonstrativo)
HTML, CSS e JS puros. Sem build. Publique a pasta no GitHub Pages, Netlify ou Vercel.

| Arquivo | Função |
|---|---|
| `index.html` | Estrutura e textos |
| `css/styles.css` | Visual (cores em `:root`: preto, verde e laranja neon) |
| `js/main.js` | Comportamento. Em `CFG`: WhatsApp, Instagram, vagas, desafio, caminhos, jornada e preços do configurador |
| `assets/favicon.svg` | Ícone da aba |
| `assets/hero.webp` | Foto de fundo do hero (academia). Troque por outra mantendo o nome. Ideal: 1600px de largura ou mais |
| `assets/trainer.webp` | OPCIONAL: foto do treinador na seção "Quem treina você" (1000x1250). Sem ela, aparece um painel gráfico |

Diferenciais comerciais: desafio de 2 minutos interativo no hero (isca de contato), caminhos por objetivo, jornada de 12 semanas, configurador de plano com preço e semana de treino, placar de resultados e vagas do mês.

Atenção: números de vagas, resultados, depoimentos, preços e CREF são de exemplo. Use o contador de vagas só com dado real.
